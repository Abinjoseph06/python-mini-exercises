# Python Mini Exercises

A beginner-friendly collection of Python programs covering core programming concepts.

## Exercises

1. `calculator.py` — functions, arithmetic, input validation, and errors.
2. `student_class.py` — classes, objects, and instance methods.
3. `even_odd.py` — conditionals and modulo arithmetic.
4. `remove_duplicates.py` — lists and dictionaries.
5. `largest_number.py` — loops and list processing.
6. `word_frequency.py` — strings, regular expressions, and dictionaries.
7. `exception_handling.py` — handling `ZeroDivisionError`.
8. `file_handling.py` — reading and writing text files.
9. `reverse_string.py` — string slicing.
10. `grade_calculator.py` — functions, conditions, and validation.

## Requirements

- Python 3.10 or later recommended
- No third-party packages are required

## Run an exercise

Open a terminal in this folder and run, for example:

```bash
python calculator.py
```

Replace `calculator.py` with the filename of the exercise you want to run.

## Learning goal

Run each program, try different inputs, and modify the code to test your understanding.
